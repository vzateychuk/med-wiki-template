# [Показатель]

`value_kind`:
- `numeric` — число (ТТГ, холестерин, IgE в единицах);
- `qualitative` — качественный итог одной сущности (ПЦР «не обнаружено», мазок «лейкоциты 25–30 в п/зр»);
- `panel-item` — один аллерген / один компонент большой панели (удобно агенту на консультации; сильные находки дублируй также в `wiki/profile/allergies.md`).

Не создавай отдельную метрику из фразы-интерпретации без собственного значения.

## Сводка

Последнее значение, день забора, статус относительно референса или по слову статуса из документа. Нет ни слова статуса, ни референса — `unknown`, значение как в документе. Для qualitative / panel-item значение в сводке — тот же текст, что в динамике.

## Динамика

Одна строка на день забора или исследования. В колонке «Дата» — этот день (`YYYY-MM-DD`). В колонке «Источник» — документ, где значение приведено. В колонке «Значение» — число **или** качественная формулировка как в документе (не выдумывать число).

| Дата | Значение | Референс | Статус | Источник |
| --- | --- | --- | --- | --- |
| YYYY-MM-DD | | | | [документ](/raw/docs/YYYY-MM-DD_type.md) |
