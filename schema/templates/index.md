# [Раздел]

Одна строка — одна страница. Тело страницы не копировать.

## Обычный каталог (`diagnoses/`, `symptoms/`, `notes/`, `references/`, …)

| Страница | Описание | Статус |
| --- | --- | --- |
| [название](/wiki/<папка>/<file>.md) | | |

- `wiki/_index.md` — строка на каждую папку wiki; колонка «Статус» не нужна.
- `wiki/diagnoses/_index.md` — статус из шапки страницы; порядок строк: active, monitoring, resolved.

## Каталог показателей — `wiki/metrics/_index.md`

Другая структура таблицы (не «Страница / Описание / Статус»):

| slug | Название | Страница |
| --- | --- | --- |
| `tsh` | Тиреотропный гормон (ТТГ) | [Тиреотропный гормон (ТТГ)](/wiki/metrics/tsh.md) |

- Ссылки только на `wiki/metrics/<slug>.md`, не на `raw/`.
- Каждая страница `wiki/metrics/<slug>.md` (кроме самого `_index.md`) должна иметь строку в каталоге.
- Строка с заполненным slug, но пустой «Страница» (файла ещё нет) — **не удалять**; при lint / ingest (схема А) создай страницу и заполни ссылку.
