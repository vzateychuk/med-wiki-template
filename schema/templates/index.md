# [Раздел]

Одна строка — одна страница: ссылка, одна строка описания, статус. Тело страницы не копировать.

| Страница | Описание | Статус |
| --- | --- | --- |
| [название](/wiki/<папка>/<file>.md) | | |

Особые каталоги:

- `wiki/_index.md` — строка на каждую папку wiki, колонка «Статус» не нужна.
- `wiki/diagnoses/_index.md` — статус из шапки страницы; порядок: active, monitoring, resolved.
- `wiki/metrics/_index.md` — список ключевых показателей: колонки «slug», «Название», «Страница». Показатель без значений ещё не имеет страницы: колонка «Страница» пустая, строку не удалять.
