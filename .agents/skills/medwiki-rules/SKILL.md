# Правило

1. Пользователь не сказал, навсегда или только на этот диалог, — спроси. Только на диалог — применяй, файлы не меняй.
2. Навсегда — выбери одно место для правила, не дублируй:
   - правило для любого маршрута — `AGENTS.md`;
   - имена файлов — `.agents/skills/medwiki-file-naming/SKILL.md`;
   - структура страницы и допустимые значения полей — шаблон в `schema/templates/`;
   - загрузка документов, ключевые показатели — `.agents/skills/medwiki-ingest/SKILL.md`;
   - проверка базы — `.agents/skills/medwiki-lint/SKILL.md`;
   - запись правил — этот файл.
3. Прочитай выбранный файл. Покажи пользователю файл, раздел и точный текст правки. Записывай после согласия.
4. Правило противоречит уже записанному — покажи оба текста и спроси, какое оставить.
5. После записи напомни: `schema/concept.md` (описание для человека) может требовать обновления; правь его только по просьбе пользователя.
